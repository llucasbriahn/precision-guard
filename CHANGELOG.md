# Changelog

## 0.1.0 — Initial local release candidate

- Added a shared protocol for evidence, uncertainty labels, scope control, honest
  action reporting, and explicit corrections.
- Added portable, Claude Code, and Codex plugin metadata and local marketplaces.
- Added a standard-library installer with preview, backups, managed-block updates,
  targeted removal, and preservation of unrelated instructions.
- Added chat instructions and documented integrations for Gemini CLI, Cursor,
  GitHub Copilot, and application-controlled prompts.
- Added architecture and contribution guides, behavioral evaluation cases,
  automated tests, package checks, reproducible ZIP builds, and CI configuration.
- Selected GPL-3.0-only for the code, instructions, and documentation.

This entry describes included functionality. It does not assert that a public
release, hosted CI run, native client installation, or model benchmark occurred.
